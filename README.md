# Wan hu 67 · Landing page

Sitio estático (HTML, CSS y JavaScript). No necesita instalar nada.

## Cómo agregar contenido
- **Videos y fotos:** editen `data.js` (instrucciones y ejemplos dentro). Las fotos van en la carpeta `img/`.
- **Blog:** editen `blog.js`; copien un bloque y péguenlo arriba de la lista.
- **Equipo:** editen la lista `EQUIPO` en `data.js`.

## Publicar en GitHub Pages
1. Suban todos estos archivos a un repositorio (el `index.html` debe quedar en la raíz).
2. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)`.
3. Esperen un par de minutos; GitHub mostrará el enlace público.
